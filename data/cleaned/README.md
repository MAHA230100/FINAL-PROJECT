# Cleaned Data Directory

This directory contains processed and cleaned datasets ready for analysis and modeling.

## Data Processing Pipeline

1. **Raw Data** → Load from `data/raw/`
2. **Cleaning** → Remove duplicates, handle missing values
3. **Feature Engineering** → Create new features, normalize data
4. **Validation** → Quality checks and validation
5. **Cleaned Data** → Save to `data/cleaned/`

## Usage

Cleaned data is automatically generated by the data processing scripts. Use the API endpoints or Streamlit UI to access this data.
