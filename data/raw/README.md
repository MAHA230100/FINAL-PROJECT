# Raw Data Directory

This directory contains raw, unprocessed datasets.

## Current Datasets

- **MIMIC Demo**: Clinical database demo data
- **Heart Disease**: Cardiovascular disease dataset
- **Body Fat**: Body composition analysis data
- **Cirrhosis**: Liver disease dataset
- **HCV Data**: Hepatitis C virus dataset
- **Stroke Data**: Healthcare stroke dataset

## Data Sources

- MIMIC-IV Clinical Database (Demo)
- UCI Machine Learning Repository
- Healthcare datasets from various sources

## Usage

Raw data should be placed in this directory before processing. Use the data cleaning scripts in the `scripts/` directory to process this data.
